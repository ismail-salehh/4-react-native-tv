# Focus styles

The focus style is the most important style in a TV app. The user must find it **in under a second** from across the room.

### Border, scale, shadow

Use more than one signal, so it works for color-blind users and on bad panels:

| Signal | How | Watch out for |
| --- | --- | --- |
| **Border / outline** | A thick (3–4 px), bright border | If the border appears only on focus, the card grows by the border width and the layout jumps. Always draw the border, transparent when not focused. |
| **Scale** | `transform: [{ scale: 1.08 }]` | Scaled content overlaps neighbors and may be clipped (see below). |
| **Shadow / glow** | `elevation` on Android, `shadow*` on iOS, `box-shadow` on web | Expensive on slow TVs, especially on web while scrolling. Keep it small or skip it on web. |
| **Color change** | Background turns light, text turns dark | Fine as an extra, not as the only signal. |

```tsx
<Pressable
  style={({ focused }) => [
    styles.card,
    focused && styles.cardFocused,
  ]}
>

const styles = StyleSheet.create({
  card: { borderWidth: s(4), borderColor: 'transparent', borderRadius: s(12) },
  cardFocused: { borderColor: '#FFFFFF', transform: [{ scale: 1.08 }] },
});
```

### Focused vs selected

Two different states that are often mixed up:

- **Focused**: where the cursor is *now*. Only one element on screen.
- **Selected**: the current choice or state, e.g. the active tab, the chosen subtitle language, the current episode. Stays after focus moves away.

They need **different** looks, and an element can be both at once:

| State | Example look |
| --- | --- |
| Normal | Grey text |
| Selected | White text + small bar under it |
| Focused | White pill background, dark text |
| Focused + selected | White pill + bar |

If selected looks like focused, the user sees two highlighted items and doesn't know where the cursor is.

### Don't clip the scale with `overflow`

A card that scales up 8% needs room around it. Parents with `overflow: 'hidden'` (and on Android, `ScrollView` / `FlatList` clip by default) cut off the edges of the focused card.

- Give the list **padding** for the growth, not the card margin: `contentContainerStyle={{ paddingVertical: s(16), paddingHorizontal: safe.x }}`.
- Don't put `overflow: 'hidden'` on rails or rows. If you need rounded corners on the image, put `overflow: 'hidden'` on the **image wrapper inside the card**, not on the card or the list.
- The focused card must draw **above** its neighbors. Give it a higher `zIndex`. In a `FlatList`, the cells are siblings, so set `zIndex` on the cell with `CellRendererComponent`, not on the card inside.
- The first and last card scale toward the screen edge. Check they don't leave the safe area.
