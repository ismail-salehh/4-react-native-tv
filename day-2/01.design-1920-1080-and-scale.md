# Design at 1920×1080 and scale

Pick **one design resolution, 1920×1080**, and build every screen at that size. Then scale it to whatever the device reports.

What each platform reports for the window (check on your own devices):

| Platform | Typical `Dimensions.get('window')` | Notes |
| --- | --- | --- |
| Android TV | 960 × 540 (dp) | A 1080p panel at density 2. A 4K panel usually reports the same dp size. |
| Apple TV | 1920 × 1080 (pt) | 4K models render at scale 2 but still report 1920×1080 points. |
| LG webOS | 1920 × 1080 (CSS px) | Set by `resolution` in `appinfo.json`. Some older apps use 1280×720. |
| Samsung Tizen | 1920 × 1080 (CSS px) | Set by the viewport in `config.xml` / `index.html`. |

Scale from the design size, so one number in the design means the same thing everywhere:

```tsx
import { Dimensions } from 'react-native';

const DESIGN_WIDTH = 1920;
const { width } = Dimensions.get('window');
export const scale = width / DESIGN_WIDTH;

export const s = (px: number) => Math.round(px * scale);

// usage
const styles = StyleSheet.create({
  card: { width: s(320), height: s(180), borderRadius: s(12) },
  title: { fontSize: s(28) },
});
```

- **Scale by width only.** TVs are always 16:9, so width and height give the same factor. Using only one keeps circles round.
- **Round the result.** Fractional pixels give blurry borders and 1 px gaps between cards.
- **Images:** request artwork at the *rendered* size × pixel ratio, not the design size. A 4K TV that renders at 1080p does not need 4K posters, and big images cost memory (see [Hardware limits](../docs/01-tv-mindset.md)).

### Check 720p and 4K

Before calling a screen done, look at it at both ends:

- **720p (1280×720):** many cheap TVs and older webOS apps run here. Text that was 20 px in the design becomes ~13 px. Is it still readable? Do 1 px borders disappear?
- **4K (3840×2160):** is the artwork sharp, or is it a stretched low-res image? Are you now loading images four times bigger than needed?

In Chrome, use device mode with 1280×720, 1920×1080 and 3840×2160. On native, change the emulator's resolution.
