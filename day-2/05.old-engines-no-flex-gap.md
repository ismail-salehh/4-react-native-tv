# Old engines: no flex `gap` (web)

`gap` / `rowGap` / `columnGap` in flexbox needs **Chromium 84**. Older LG and Samsung TVs (see [Old browser engines](../docs/01-tv-mindset.md#old-browser-engines-on-lg-and-samsung-tvs)) ignore it, so cards render touching each other. The page looks fine in desktop Chrome and broken on the TV.

React Native has supported `gap` since 0.71, and react-native-web passes it through as CSS `gap`, so the same style works on native and breaks on old engines.

Fallback: **use margins instead of `gap`** in shared components.

```tsx
// instead of: <View style={{ flexDirection: 'row', gap: s(24) }}>
<View style={{ flexDirection: 'row' }}>
  {items.map((item, i) => (
    <Card key={item.id} item={item} style={i > 0 && { marginLeft: s(24) }} />
  ))}
</View>
```

For `FlatList`, use `ItemSeparatorComponent` or a margin on each item.

> **Verify (web):** check what your react-native-web version outputs for `gap` (inspect the element), and check the lowest engine you support. If it is Chromium 84 or newer everywhere, `gap` is fine. A lint rule banning `gap` in shared styles stops it coming back.
