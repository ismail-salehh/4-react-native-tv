# Font sizes, contrast, scrims over artwork

### Font sizes (at 1920×1080 design size)

| Use | Size |
| --- | --- |
| Screen title | 48–56 px |
| Section / rail title | 32–36 px |
| Body, card title | 24–28 px |
| Metadata, captions | 20–22 px |
| Never below | ~20 px |

- **Use few sizes and weights.** Three or four sizes are enough.
- **Limit line length** to about 60 characters and descriptions to 2–3 lines. Nobody reads a paragraph from the sofa.
- **Prefer medium/semibold weights.** Thin fonts break up on TV panels and at 720p.

### Contrast

- Aim for at least **4.5:1** for text (WCAG AA), more for small text.
- Avoid pure white on pure black for large text areas. It glows (blooms) on many panels. Off-white like `#E8E8E8` on near-black like `#101014` reads better.
- TVs differ a lot in color and brightness, and many run in "vivid" mode. Don't rely on subtle grey differences.

### Scrims over artwork

Text on top of a poster or hero image is unreadable when the image is bright behind it. Put a **scrim** (a dark gradient) between the image and the text:

```tsx
import LinearGradient from 'react-native-linear-gradient';

<ImageBackground source={{ uri: hero.image }} style={styles.hero}>
  <LinearGradient
    colors={['rgba(0,0,0,0.85)', 'rgba(0,0,0,0)']}
    start={{ x: 0, y: 0 }}
    end={{ x: 0.7, y: 0 }}
    style={StyleSheet.absoluteFill}
  />
  <Text style={styles.heroTitle}>{hero.title}</Text>
</ImageBackground>
```

On web you can use a CSS `linear-gradient` background on a plain `div`. Test the scrim with the **brightest** artwork you have, not the one in the design file.

### A short note on aspect ratios

- The screen is **16:9**. Design everything for it; don't support portrait.
- Common artwork shapes: **2:3** posters, **16:9** landscape tiles and heroes, **1:1** for channels/avatars.
- Fix the size of the box and let the image fit it (`resizeMode="cover"`). Never let image size decide layout; a slow or missing image then shifts the whole rail and moves focus.
- `aspectRatio` works in RN styles, but CSS `aspect-ratio` needs Chromium 88. On old LG/Samsung engines, compute the height yourself: `height: s(width * 1.5)`.
