# Focus styling never rely on hover alone

Because most TV users never hover. Android TV, Apple TV, and Samsung remotes have no pointer, so `:hover` (or `onHoverIn`) never fires for them. If the focus look exists only as a hover style, D-pad users get no visible cursor at all and the app looks frozen.

Hover only happens on some devices, mainly the LG Magic Remote, or a mouse plugged into a box. There, hover should **move focus** to the hovered element, and the element should then show its normal focus style. So the style is driven by the *focused* state, and hover is just one more way to become focused. That way, D-pad users and pointer users always see the same single highlighted element, never two (one hovered, one focused).
