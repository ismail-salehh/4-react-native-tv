# Right-to-left layouts flip left/right focus direction

In Arabic, layouts are mirrored: the menu is on the **right**, rails start on the **right** and scroll to the left, and "next" is to the **left**.

### What flips by itself

- **Native:** with `I18nManager.forceRTL(true)` (needs an app restart), `flexDirection: 'row'` lays out from right to left, and `marginStart`/`paddingEnd`/`start`/`end` swap sides.
- **Web:** `dir="rtl"` on `<html>` does the same for flex rows and logical properties.
- **The D-pad stays physical.** Pressing Right always moves to the element **on the right of the screen**. Native focus engines find it by position, so this just works.

### What you have to flip yourself

Anything where *your code* decides what Left or Right means:

- **`nextFocusLeft` / `nextFocusRight`** set by hand. In RTL, the "previous" item is on the right.
- **Opening the side menu.** "Press Left from the first card to reach the menu" becomes "press **Right**" because the menu is now on the right.
- **Custom key handling** (`onArrowPress` in Norigin, `useTVEventHandler`): "Right = next episode", "Left = seek back". For lists and navigation, flip with the layout. For **media seek bars**, check what your product wants; many apps keep time running left-to-right even in RTL.
- **Animations and icons:** a menu sliding in from the left, an arrow `>` meaning "more", a progress bar. Flip direction with `I18nManager.isRTL`.
- **Scroll position:** a horizontal list in RTL starts at the right end. Check `initialScrollIndex` and "scroll focused item into view" logic on both directions.

Write code in **start/end**, not left/right, and convert to physical keys in one place:

```ts
import { I18nManager } from 'react-native';

const isRTL = I18nManager.isRTL;

// "forward" = the direction lists continue in
export const KEY_FORWARD  = isRTL ? 'left'  : 'right';
export const KEY_BACKWARD = isRTL ? 'right' : 'left';
```

```tsx
// styles: use start/end
card: { marginStart: s(24) },     // not marginLeft
menu: { start: 0 },               // not left: 0
```

> **Verify (web):** check whether your spatial navigation library has an RTL option (e.g. an `rtl` flag at init) and what it changes. Test a full RTL pass on a real TV: menu, rails, grids, modals, and the player.
