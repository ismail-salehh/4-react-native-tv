# Glossary

| Term | Meaning | Example |
| --- | --- | --- |
| **Screen** | A full-page destination the user navigates to. Owns its own initial focus and is a step in the Back history. | Home, Details, Search, Player |
| **Route** | The address of a screen: a name plus params. What you navigate *to*, store, and restore. | `{ name: 'Details', params: { id: 'm42' } }` |
| **Overlay** | A layer drawn on top of the current screen without leaving it. Takes focus (and traps it) while open; Back closes it first. | Exit confirm, track picker, player controls, toast |
| **Component** | A reusable building block. Knows nothing about routes or navigation; gets data and callbacks as props. | `Card`, `Rail`, `Button`, `Player` |

Rule of thumb: if Back should close it and stay on the same page, it's an **overlay**. If Back should return to the previous page, it's a **screen**.
