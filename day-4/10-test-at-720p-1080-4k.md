# Test at 720p, 1080p and 4K, and on a low-end device

The same app runs on 720p sticks, 1080p TVs and 4K TVs, and on hardware from very fast to very slow. Check both ranges before release.

### Three resolutions

| Resolution | Look for |
| --- | --- |
| **720p** (1280×720) | Text still readable from the couch, 1 px borders not lost, focus border still visible, nothing overlapping |
| **1080p** (1920×1080) | The design size: should match the design exactly |
| **4K** (3840×2160) | Artwork sharp (not upscaled), but not loading huge images; focus styles and safe areas scaled correctly |

How to switch:

- **Android TV emulator**: create emulators at 720p and 4K, or change the size of a running one, then reset it after:
  ```sh
  adb shell wm size 1280x720
  adb shell wm density 213   # 720p TVs usually run at tvdpi
  adb shell wm size reset && adb shell wm density reset
  ```
- **Apple TV simulator**: Apple TV (1080p) and Apple TV 4K simulators.
- **Web**: Chrome device mode with 1280×720, 1920×1080 and 3840×2160. On the real TV, log `window.innerWidth`, `innerHeight` and `devicePixelRatio`: many TVs render the web app at 1920×1080 (or 1280×720) even on a 4K panel.

Use the same screen and the same focus positions at each size: first card, last card, longest title, modal open. Screenshots side by side make differences obvious. See also [Check 720p and 4K](../docs-2/01-layout-and-styling.md#check-720p-and-4k).

### A low-end device

Use the slowest device you support, with a **release build**, for every release:

- **Startup**: time from launch to the first focused card.
- **Key response**: press and hold Right on a long rail; focus should follow the remote and stop when you let go.
- **Scrolling**: rails and grids scroll without stutter.
- **Memory**: browse five sections, return to Home, repeat ten times; memory should level off, and the app should not be killed or reloaded.
- **Video**: start and stop playback a few times; the UI should still be responsive afterwards.
- **Coming back from the background**: press Home, open another app, come back; focus and data should still be there.

Write the numbers down for each release (see [Measure on the weakest real device](../docs-3/01-performance.md#measure-on-the-weakest-real-device-with-a-release-build)) so you notice when they get worse.
